# Security Policy

Report vulnerabilities privately by email to oss@agentworkshq.dev. Please do not open a public issue for a security problem. Do not include real documents, questions, answers or secrets.

Only the latest 0.x release is supported.

Reports on these topics are especially welcome:

- document uploads and the parsers behind them
- file name and path handling, in uploads and in the filesystem source
- tenant isolation
- prompt injection through retrieved text
- the REST endpoints, including authentication and role checks
- document text, questions or answers leaking into logs or error responses

What the library does and cannot protect against is described under [Security and privacy](README.md#security-and-privacy) in the README.
